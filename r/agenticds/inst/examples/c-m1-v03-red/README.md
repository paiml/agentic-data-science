# c-m1-v03-red

Red first. Copies the package to a scratch directory, changes the NA
policy in `R/p1.R` so it keeps every row, runs the p1 tests on the
copy and prints the counts and the failing tests. The run passes only
when the tests catch the change.

Run from the repository root: `source("r/agenticds/inst/examples/c-m1-v03-red/run.R")`
